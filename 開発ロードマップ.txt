■ 次にすること（段階ごとに詳しい計画を立ててから着手する。1 段階＝1 版＝1 PR の見込み）
1. 土台（v1.00）
   - Electron の骨組み（main.js・preload.js）と、アプリの画面 mock_v1.00.html を作る。CheckListMaker から写す。
   - npm install で Electron と electron-builder が社内のネットワークから入るかを、最初に確かめる。
   - インストーラ（npm run dist）が作れること、インストールして起動できることを確かめる。
   - 最初の画面（画面設計の一覧）、新規作成、アプリの中への自動保存、元に戻す、拡大縮小、画面の移動、メニューバー。
   - アプリの中の保存先（localStorage・IndexedDB・アプリのフォルダのファイル）は、この段階の計画で決める。
2. 画面の中身
   - 画面の枠とマス目、部品の種類ごとの見た目（一般的な名前の部品）、赤い番号、番号ごとの設定の一覧表（右か下）、吹き出し。
   - 4 種類の画面（入力・詳細、一覧、グラフ・集計、進み具合と操作ボタン）に要る部品をそろえる。
3. 複数の画面
   - 左に画面の一覧を並べ、押した画面だけを右に出す。画面の追加・並べ替え・削除。
4. 書き出しと受け渡し
   - ブラウザだけで開けて編集もできる HTML ファイルへの書き出しと、その取り込み。
   - PDF（printToPDF・1 画面＝1 ページ）と PNG（1 画面＝1 枚）。
