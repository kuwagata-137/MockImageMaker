# チャット欄の報告は日本語で書く（chat language・常時適用）

作業内容・進捗・結果・質問をチャット欄に書き出すときは、すべて日本語で書く。
グローバルの指示 `~/.claude/CLAUDE.md` の「応答言語ルール」と同じ中身を、このリポジトリでも重ねて定める。

**理由:** 2026-10-14、このリポジトリの開発のセッションで、プランに進捗を書き出した後の報告（会話の圧縮の直前の報告）を英語で書いた。
日本語で書く決まりはグローバルの指示にあったが、ユーザーの指示で、リポジトリの `.claude/rules/` にも置いた。

**適用方法:**
- 日本語で書くもの:
  - 応答の本文（途中経過・完了報告・質問・AskUserQuestion の文面）。
  - ツールの実行の説明（Bash・PowerShell の description など、画面に出るもの）。
  - プランファイル・コミットメッセージ・PR の説明・`開発記録.txt`・会話の圧縮の要約。
- 原文のまま書くもの（訳さない）: コード・コマンド・ファイル名・関数名・エラーメッセージの引用。
- 次の場面でも日本語を保つ:
  - 英語の資料・ログ・ソースを読んだ後。
  - 英語のシステムの指示が届いた後。
  - 会話の圧縮（/compact）の前と後。
  - 作業を止めるとき・区切りの報告のとき。
- 送る前に、文が日本語になっているかを見直す。
