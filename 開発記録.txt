■ 2026-10-08 立ち上げ
- ビジネスダイアグラムメーカーから分かれて、別のリポジトリで作ることにした。理由は 引継書.md の 3 章。
- 引継書 9 章の 1〜5（ファイルを置く・.gitignore・Puppeteer・フック）を、クラウドのセッションで済ませた。
  - GitHub のリポジトリが空で main がなかったため、ユーザーの指示で、この準備のコミットだけは PR を通さずに main にも置いた。
  - フックの登録は、参考の手順の「絶対パス」でなく $CLAUDE_PROJECT_DIR で書いた。クラウドと共同開発者のデスクトップの両方で同じ設定を使うため。
  - フックの対象は Bash と PowerShell の両方にした（引継書 9 章の 5 の任意の項目）。止めるのは main への push だけなので、足しても困ることはない。
  - フックの文言から、ビジネスダイアグラムメーカーの記憶（memory）の名前を消した。このリポジトリにはない記憶のため。参考/ の写しは元のまま。
  - Puppeteer は、クラウドのセッションでは npm の取得が拒まれた（403）ため、package.json に書くだけにした。
